## 4. README HERO BLOCK (paste at the very top of README.md)

```markdown
# Binary Matrix Web3 dApp — Live Demo (Solidity + Next.js)

A production-grade, end-to-end demo of a decentralized binary forced-matrix
protocol for affiliate / network-reward structures.

**🔗 Live demo:** https://web3-binary-matrix-dapp.vercel.app/

## What it demonstrates
- Immutable 2×N binary forced matrix with automatic BFS placement
  (Solidity Registry contract, non-transferable SBT membership)
- Campaign contracts with dynamic upline compression + instant stablecoin fee splits
- 72-hour grace-period safety holding (release / reverse)
- "Web2.5" onboarding: email/social login + embedded wallet (MetaMask supported)
- Next.js + TypeScript dashboard, React Flow tree visualization, real-time analytics
- Off-chain Node.js indexer: BFS runs off-chain for ~87% gas saving per placement

> **Demo note:** the contracts are real, Foundry-tested Solidity running against
> a chain simulator so the full user journey works without testnet setup.
> Production path: deploy to Base L2 + ERC-4337 account abstraction (Privy/Biconomy)
> + PostgreSQL sync layer.
```
